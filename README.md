## ✨ المزايا

- **عربي بالكامل** باتجاه RTL صحيح، وخط `Tajawal` مع بدائل من خطوط النظام.
- **متجاوب** من عرض ٣٢٠ بكسل حتى الشاشات الكبيرة (تصميم الموبايل أولاً).
- **بدون تبعيات**: لا npm ولا build — افتح الملف واشتغل.
- **هوية مبنية على اللوغو**: لون البراند `#FF503F` مسحوب من اللوغو نفسه.
- **جاهز لمحركات البحث**: وصف لكل صفحة، Open Graph، بيانات منظّمة JSON-LD، `sitemap.xml`، `robots.txt`.
- **إمكانية وصول**: تنقّل بالكيبورد، سمات `aria`، احترام `prefers-reduced-motion`، تباين لوني مدروس.

## 📁 بنية المشروع

```
index.html              الرئيسية (هيرو، أرقام، نبذة، خدمات، مزايا، خريطة التغطية، خطوات، شركاء)
about.html              من نحن: القصة، الرؤية، الرسالة، الأهداف، الخطط، التوجهات، القيم
faq.html                الأسئلة الشائعة (أكورديون + بيانات FAQ منظّمة)
blog.html               قائمة المقالات
blog/post-1..3.html     ثلاث مقالات جاهزة
contact.html            نموذج تواصل + معلومات الاتصال
assets/css/style.css    كل الستايل (المتغيّرات بأعلى الملف)
assets/js/main.js       القائمة، الأكورديون، الحركات، العدّادات، نموذج واتساب
assets/img/             اللوغو والأيقونات والرسومات
robots.txt · sitemap.xml · favicon.png · 404.html

```

## 🚀 التشغيل محلياً

أي واحدة من هذي كافية:

```bash

# أو شغّل سيرفر محلي:

# ثم افتح: http://localhost:8000
```

## 🎨 تغيير الألوان

كل ألوان الموقع بمكان واحد — أول `assets/css/style.css` داخل `:root`:

```css
:root{
  --brand:      #FF503F;   /* لون اللوغو — الأزرار والأيقونات */
  --brand-600:  #ED4130;   /* درجة أغمق للتأثيرات */

}
```

تبديل `--brand` لوحده يغيّر مظهر الموقع كله.

## 🗺️ خريطة التغطية

بصفحتي `index.html` و `contact.html` أكو قسم `#coverage` يعرض **خريطة العراق بكل محافظاتها** بلون البراند، وعليها دبوس يأشّر مكتبنا ببغداد.

- الخريطة **SVG مرسوم داخل الصفحة** — ما يحتاج إنترنت ولا مكتبة خرائط ولا مفتاح API، ويطلع واضح بأي حجم شاشة.
- حدود المحافظات مأخوذة من بيانات [Natural Earth](https://www.naturalearthdata.com/) (ملكية عامة — بدون قيود استخدام).
- كل محافظة عليها اسمها يظهر لمّا تمرّر الماوس فوقها، وبجنب الخريطة قائمة بالـ ١٩ محافظة.

**تغيير ألوان الخريطة:** من `assets/css/style.css` تحت `13.5 خريطة تغطية العراق`:

| الكلاس | شنو يغيّر |
|---|---|
| `.iraq-map .gov` | لون المحافظات (يستعمل التدرّج `mapFill` بأعلى الـ SVG) |
| `.iraq-map .gov:hover` | لون المحافظة عند مرور الماوس |
| `.iraq-map .gov.is-hq` | لون محافظة بغداد (مقرّ الشركة) |
| `.iraq-map .hq-pin` · `.hq-pulse` | لون الدبوس ونبضته |

**تغيير عنوان المكتب على الخريطة:** ابحث عن `hq-t1` و `hq-t2` بملفي `index.html` و `contact.html`:

```html
<text class="hq-t1" x="188" y="28">بغداد — المنصور</text>
<text class="hq-t2" x="188" y="52">شارع ١٤ رمضان</text>
```

**تغيير مكان الدبوس:** الدبوس محسوب على إحداثيات المنصور. إذا انتقل المكتب، غيّر قيم `translate(...)` بالمجموعتين `class="hq"` و `class="hq-card"` — أو خبّرني بالعنوان الجديد وأعيد توليد الخريطة.

## ⚠️ محتوى نموذجي لازم تبدّله

الموقع جاهز شكلاً، بس هذي أرقام ونصوص **افتراضية** حطيناها كمثال — بدّلها بمعلوماتك الحقيقية قبل النشر:

- **أرقام الإنجازات** بالرئيسية (`+٥٠٬٠٠٠ طلب`، `١٩ محافظة`، `+١٢٠ مندوب`، `٩٨٪`) — داخل قسم `<section class="stats">` بملف `index.html`.
- **تواريخ المقالات** بملف `blog.html` وصفحات `blog/`.
- **الدومين** `https://zajel-express.com` بملفي `sitemap.xml` و `robots.txt`.
- **روابط canonical و og:url** — مكانها معلّم بتعليق داخل `<head>` بكل صفحة.
- **أوقات الدوام** إذا تختلف عن المكتوب.

## 📨 نموذج التواصل

الموقع ثابت وما بيه سيرفر، فنموذج «اتصل بنا» **يجمّع البيانات ويفتح محادثة واتساب** برسالة جاهزة على رقم الشركة. ما تحتاج أي خدمة خارجية ولا اشتراك ولا بريد إلكتروني.

لو حبيت تستقبل الرسائل بالبريد تلقائياً، تكدر تربط النموذج بخدمة مثل Formspree بتغيير `action` و `method` بالعنصر `<form id="contactForm">`.

## 🌍 النشر

الموقع ملفات ثابتة — ينشر على أي استضافة بدون بناء ولا إعدادات.

### المقارنة بسرعة

| الاستضافة | مجانية | علامة مائية أو إعلانات | الرابط المجاني | استعمال تجاري | النطاق الشهري |
|---|---|---|---|---|---|
| **Cloudflare Pages** | نعم | ❌ ما بيها | `اسمك.pages.dev` | ✅ مسموح | غير محدود |
| **Netlify** | نعم | ❌ ما بيها | `اسمك.netlify.app` | ✅ مسموح | ١٠٠ غيغا |
| GitHub Pages | نعم | ❌ ما بيها | `user.github.io/ahmed` | ⚠️ شروطها تمنع تشغيل موقع تجاري | ١٠٠ غيغا |
| Vercel (خطة Hobby) | نعم | ❌ ما بيها | `اسمك.vercel.app` | ⚠️ ممنوع تجارياً بشروط الخطة المجانية | ١٠٠ غيغا |

**ولا وحدة من هذي تحط شعار أو بانر على الموقع** — الصفحة تطلع نظيفة ١٠٠٪. الشي الوحيد إن اسم المنصة يظهر بالرابط المجاني، وينحذف بربط دومين خاص (الربط مجاني بكلهن، بس الدومين نفسه بحدود ١٠–١٥ دولار بالسنة).

**التوصية:** Cloudflare Pages — نطاق غير محدود، مسموح تجارياً، وسيرفراتها قريبة من العراق فتفتح أسرع.

### Cloudflare Pages

1. سجّل بحساب مجاني على [dash.cloudflare.com](https://dash.cloudflare.com) ثم **Workers & Pages → Create → Pages → Connect to Git**.
2. اختر هذا المستودع والفرع.
3. الإعدادات:

| الحقل | القيمة |
|---|---|
| Framework preset | `None` |
| Build command | (اتركه فاضي) |
| Build output directory | `/` |

4. **Save and Deploy** — خلال دقيقة يطلع الرابط.

### Netlify

**سحب وإفلات (بدون حساب):** افتح [app.netlify.com/drop](https://app.netlify.com/drop) وارمي مجلد المشروع أو ملف zip.

**ربط بـ GitHub (نشر تلقائي):** **Add new site → Import an existing project → GitHub**، واختر المستودع. الإعدادات تنقرأ من `netlify.toml` (بدون أمر بناء، مجلد النشر `.`).

### GitHub Pages

**Settings → Pages → Source: Deploy from a branch**، اختر الفرع والمجلد `/ (root)` ثم **Save**.

> ملاحظة: على GitHub Pages الموقع ينفتح على مسار فرعي (`/ahmed/`)، فصفحة `404.html` روابطها راح تنكسر لأنها مبنية على جذر الدومين. Cloudflare Pages و Netlify ما عندهم هالمشكلة.

## 🧪 اللي تم فحصه

- كل الروابط والملفات الداخلية تفتح بدون أخطاء (٢١ رابط).
- لا يوجد سكرول أفقي بعرض ٤٠٢ بكسل ولا ١٣٦٦ بكسل.
- قائمة الموبايل: تفتح وتنغلق بالزر وبمفتاح `Esc`.
- الأكورديون يشتغل وتتحدث سمة `aria-expanded`.
- نموذج التواصل يبني رابط واتساب صحيح بالمعلومات المدخلة.
- console المتصفح خالي من الأخطاء.
- خريطة العراق تطلع صح بالموبايل والديسكتوب، وبطاقة العنوان داخل حدود الخريطة.
